Guide d'utilisation & Raccourcis

Les 5 étapes VideoPlay Studio :

  1. 1. Ajoutez votre vidéo : Collez n'importe quel lien YouTube public ou non répertorié.
  2. 2. Montez sans modifier : Définissez In/Out, scindez et supprimez des segments. Le moteur saute automatiquement les coupes pendant la lecture !
  3. 3. Créez le script : Ajoutez des obstacles (Jeu d'action) ou des paliers de vitesse (Virtual Run).
  4. 4. Testez en direct : Basculez dans le lecteur immersif avec personnage 2D animé ou cockpit treadmill.
  5. 5. Exportez : Récupérez le fichier script .json complet prêt pour la diffusion.
