Guide & Raccourcis

Les 5 étapes

  1. Ajoutez un lien YouTube public ou non répertorié.
  2. Montez sans modifier : In/Out, coupes, son coupé.
  3. Créez le script : actions de jeu ou Virtual Run.
  4. Testez avec « Tester le Jeu / Run ».
  5. Exportez le .json dans ./games ou ./virtual-run de l'app TV.

Raccourcis

Espace : Lecture / Pause
I / O : Point In / Out
S : Coupe de 2 s au curseur
M : Son on/off
← / → : ±1 s (Shift : ±0,1 s)
+ / - : Zoom timeline
1 à 0 : Poser une action
Ctrl+Z / Ctrl+Y : Annuler / Rétablir

🤖 Détection automatique des actions

Gemini regarde la vidéo YouTube (publique) et propose les moments où le joueur doit agir. Vous relisez la liste, puis vous l'ajoutez à la timeline. Les temps peuvent être décalés d'environ 1 s : vérifiez avec « Aperçu » ou le mode test, puis ajustez.
